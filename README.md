# 🌌 Вселенная Shiren

Интерактивный 3D-сайт на **Three.js**: тёмный космос, шейдерное звёздное поле, туманность и полярное сияние, светящееся ядро и **планеты-проекты** на орбитах. Наведи на планету — она подсветится и покажет подпись, кликни — камера плавно подлетит к ней, а справа появится панель с описанием, стеком и кнопкой «Открыть на GitHub».

**▶ Живая версия: https://shirenos.github.io/universe/**

## ✨ Что внутри

- **Вступительная анимация** — камера влетает из глубины космоса, ядро разгорается, появляются планеты и заголовок (можно пропустить).
- **Звёздное поле** — десятки тысяч частиц одним draw call'ом, мерцание и размер считаются в вершинном шейдере.
- **Туманность** — процедурный fBm-шум на небесной сфере с градиентами индиго → фиолетовый → циан, плюс лента **полярного сияния**.
- **Планеты** — процедурные шейдеры поверхности (без текстур), освещение от ядра, **свечение атмосферы** (fresnel), кольца, спутник.
- **Пояс астероидов** — `InstancedMesh`, один draw call.
- **Кометы** — хвосты из точек, один draw call.
- **Постобработка** — `UnrealBloomPass` + `OutputPass` (ACES tone mapping).
- **Управление** — `OrbitControls` с инерцией, параллакс слоёв от мыши, перелёты камеры, жесты на телефоне (свайп / щипок / тап).
- **Доступность** — навигация с клавиатуры (кнопки планет, `Esc`, `←`/`→`), `aria`-разметка, `prefers-reduced-motion` и кнопка «Анимации: вкл/выкл» (выбор запоминается).
- Звука нет. Личных данных на сайте нет — только публичные проекты.

## ⚡ Производительность

- `pixelRatio` ограничен (≤ 2 / 1.5 / 1 в зависимости от уровня качества) и ещё «бюджетом» пикселей на кадр.
- Три уровня качества (`high` / `medium` / `low`) выбираются по устройству (ядра, память, touch). На `low` отключается bloom и полярное сияние, уменьшаются звёзды и астероиды.
- **Сторож FPS**: если кадры стабильно медленные — качество автоматически снижается.
- В режиме «Анимации: выкл» сцена перерисовывается только при необходимости.
- Всего ~20 draw call'ов (звёзды, небо, сияние, ядро, планеты, пояс, кометы — по одному-два на объект).
- Если WebGL недоступен — показывается обычный список проектов (fallback).
- Three.js и шрифт Inter берутся из `npm` и собираются локально: **никаких CDN**.

Параметры URL для отладки: `?q=low|medium|high` — принудительное качество, `?adaptive=0` — выключить сторож FPS, `?nointro` — без заставки; `#habit`, `#schedule`, `#universe` — сразу открыть планету.

## 🛠 Стек

Three.js · GLSL · Vite · JavaScript (ES-модули) · GitHub Actions · GitHub Pages

## 🚀 Запуск

```bash
npm install
npm run dev       # http://localhost:5173/universe/
npm run build     # статическая сборка в dist/
npm run preview   # предпросмотр сборки на http://127.0.0.1:4173/universe/
```

Базовый путь сборки — `/universe/` (см. `vite.config.js`), потому что сайт живёт в проекте-репозитории GitHub Pages.

## 📦 Деплой

Каждый пуш в `main` запускает workflow [`deploy.yml`](.github/workflows/deploy.yml): `npm ci` → `vite build` → публикация `dist/` через GitHub Pages (Actions).

## 🧪 Автопроверка

`scripts/check.mjs` — headless-проверка через Chrome и SwiftShader (WebGL без GPU): ждёт готовности сцены, собирает ошибки консоли и сохраняет скриншот.

```bash
node scripts/check.mjs "http://127.0.0.1:4173/universe/?q=high&adaptive=0#habit" shot.png --mode=focus
```
